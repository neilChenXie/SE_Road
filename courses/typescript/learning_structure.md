# TypeScript 学习计划

## 课程概述

TypeScript 是 JavaScript 的超集，添加了静态类型系统。本课程基于你已经掌握的 JavaScript 知识和 Node.js 开发经验，帮助你快速掌握 TypeScript 的核心概念和实际应用。

## 章节规划

### 第一章：入门与环境搭建
- TypeScript 简介：为什么需要类型？
- 与 JavaScript 的关系
- 安装与配置
- tsconfig.json 详解
- 编译与运行
- **实践目标**：能够独立配置 TypeScript 项目

### 第二章：基础类型
- 原始类型：string、number、boolean
- 数组与元组
- 对象类型
- any、unknown、never
- 类型推断与类型注解
- **实践目标**：掌握 TypeScript 的基础类型系统

### 第三章：接口与类型别名
- interface 定义对象形状
- type 别名
- 两者区别与选择
- 联合类型与交叉类型
- **实践目标**：能够定义复杂的数据结构

### 第四章：函数
- 函数类型定义
- 参数类型（可选、默认、剩余参数）
- 函数重载
- 箭头函数与类型
- **实践目标**：编写类型安全的函数

### 第五章：类与面向对象
- 类的基本语法
- 访问修饰符（public、private、protected）
- 抽象类
- 接口实现
- **实践目标**：掌握 TypeScript 面向对象编程

### 第六章：泛型
- 泛型函数
- 泛型接口
- 泛型类
- 泛型约束
- **实践目标**：编写可复用的类型安全代码

### 第七章：实战项目
- TypeScript + Koa 项目
- 类型声明文件
- 项目结构最佳实践
- **实践目标**：能够开发完整的 TypeScript 项目

## 前置知识

- JavaScript ES6+ 语法
- Node.js 基础
- 了解面向对象概念更佳

## 学习建议

1. **对比学习**：时刻对比 JavaScript，理解 TypeScript 带来的好处
2. **动手实践**：类型系统需要大量练习才能熟练
3. **善用 IDE**：VS Code 对 TypeScript 支持极好，学会利用类型提示
4. **渐进式采用**：可以在现有 JS 项目中逐步引入 TS
