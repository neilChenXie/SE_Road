# 工时系统数据库功能开发日志

**日期**: 2026-03-23

## 需求

将项目名称和工作性质从硬编码改为从数据库读取，支持动态管理。

## 技术选型

- **数据库**: SQLite (轻量级，无需安装数据库服务)
- **后端**: Node.js + Express
- **依赖**: better-sqlite3, cors, express

## 新增文件

```
server/
├── package.json      # Node.js 依赖配置
├── database.js       # SQLite 数据库初始化脚本
└── server.js         # Express API 服务
```

## 数据库表结构

### project_types (项目名称表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT | 主键 |
| name | TEXT | 项目名称 |
| created_at | DATETIME | 创建时间 |

### project_natures (工作性质表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | TEXT | 主键 |
| name | TEXT | 工作性质名称 |
| created_at | DATETIME | 创建时间 |

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/project-types | 获取项目名称列表 |
| GET | /api/project-natures | 获取工作性质列表 |
| POST | /api/project-types | 添加项目名称 |
| POST | /api/project-natures | 添加工作性质 |
| PUT | /api/project-types/:id | 更新项目名称 |
| PUT | /api/project-natures/:id | 更新工作性质 |
| DELETE | /api/project-types/:id | 删除项目名称 |
| DELETE | /api/project-natures/:id | 删除工作性质 |
